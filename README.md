# Last Light

2D-гра в піксельному стилі на Unity. Ви — водій нічного тролейбуса, який везе до кінцевої зупинки останній живий Вогник. Якщо він згасне, ніч лишиться назавжди.

Папка проєкту й меню редактора досі називаються Night Trolleybus: це стара назва гри.

## Ігровий процес

Партія складається з поїздок між зупинками, а маршрут ви обираєте самі на мапі з розгалуженнями.

- **У салоні** (вид збоку) ви ведете тролейбус, стежите за Вогником, зігріваєте салон, полагоджуєте поломки й підбираєте пасажирів.
- **На зупинках** (вид зверху) ви шукаєте припаси в темряві й відбиваєтеся від ворогів. Розташування кімнат і предметів щоразу випадкове.
- **Між зупинками** трапляються події з вибором і наслідками.

### Що треба тримати під контролем

| Показник | Що означає |
| --- | --- |
| Вогник | Головна мета: якщо згасне, гру програно |
| Тепло | Температура в салоні |
| Енергія | Живлення тролейбуса |
| Страх | Зростає через темряву, ворогів і деяких пасажирів |
| Серця | Здоров'я героя: якщо закінчаться, гру програно |

### Типи зупинок

| Зупинка | Що дає |
| --- | --- |
| Депо | Енергія |
| Супермаркет | Свічки |
| Магазин зброї | Зброя за квитки |

### Вороги

- **Тіні** нападають зблизька.
- **Привиди** з'являються з третьої зупинки. Вони тримаються на відстані й тягнуть героя променем: спершу сповільнюють, а якщо промінь триває довго, завдають шкоди.

### Поломки

Кожну несправність усуває своя міні-гра.

- **Штанги:** тричі поспіль влучити, коли штанга над дротом.
- **Запобіжник:** вибрати запобіжник на потрібний струм.
- **Проводи:** з'єднати проводи в указаному порядку.

## Керування

| Клавіша | Дія |
| --- | --- |
| A / D | Хода в салоні |

| W / S за кермом | Швидкість |
| Миша | Погляд на зупинці |
| ЛКМ | Удар |
| E | Дія |
| F | Спалах |
| R | Підсвітити |
| G | Зігріти салон |
| Q | Використати предмет |

У міні-грах ремонту працюють пробіл, клавіші 1–3 і миша, а Esc означає «відійти».

## Як запустити

1. Встановіть Unity **6000.6.7f1** (проєкт використовує URP 2D і Input System).
2. Відкрийте кореневу папку репозиторію через Unity Hub.
3. Відкрийте сцену `Assets/_Project/Scenes/Boot.unity` і натисніть Play.

У `Boot` живуть постійні системи гри, а решта сцен довантажується поверх неї. Тому запускати гру з іншої сцени не варто.

## Структура проєкту

```
Assets/_Project/
├── Art/       спрайти й тайлсети
├── Audio/     звуки й музика
├── Data/      ScriptableObject: предмети, пасажири, канали подій
├── Prefabs/   вороги та інші префаби
├── Scenes/    Boot, Bus, RouteMap і Stops/ (Depot, GunShop, Market)
├── Video/     вступна й фінальна катсцени
└── Scripts/
    ├── Core/        запуск гри, стани, аудіо, налаштування, локалізація
    ├── Editor/      збирачі сцен і піксельні текстури
    ├── Flame/       Вогник і його здібності
    ├── Items/       предмети, інвентар, лут
    ├── Narrative/   події та сюжетний текст
    ├── Passengers/  пасажири
    ├── Player/      рух, взаємодія, здоров'я героя
    ├── Route/       мапа маршруту й поїздки
    ├── Save/        збереження
    ├── Stops/       генерація зупинок, темрява, вороги
    ├── UI/          HUD, меню, інвентар, вікно ремонту
    └── Vehicle/     тролейбус, поломки й ремонт
```

## Нотатки для розробки

- **Збирання сцен.** Сцени генеруються з коду через меню `Night Trolleybus/Scenes`. Команди збирання **перезаписують** сцени, тому ручні правки в них зникнуть: зміни краще вносити в збирачі (`Scripts/Editor`).
- **Текстури.** Більшість спрайтів у `Art/Sprites/Generated` малює код у `Scripts/Editor/PixelArt.cs`. Файл створюється, лише якщо його немає, тому після зміни малюнка старий PNG треба перезаписати окремо.
- **Переклад.** Гра підтримує українську й англійську. Ключами в `Core/Loc.cs` є українські рядки, тому кожен новий видимий текст треба додати туди. Тексти меню лежать в `UI/MenuText.cs`.
- **Збереження.** Гра пише `save.json` у `Application.persistentDataPath`. На Windows це `%USERPROFILE%\AppData\LocalLow\DefaultCompany\Last Light\`.
